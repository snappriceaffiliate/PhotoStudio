# PickSnap logo

The logo is the **tick horizon** icon (a photo whose horizon is a tick) beside the name
**picksnap** in Sora SemiBold. The lettering is converted to shapes, so no font needs to be
installed to use the SVG or PNG files.

## Colours

| Name | Hex | Used for |
| --- | --- | --- |
| Indigo | `#3b2f8f` | Icon sky, "snap" on light backgrounds |
| Coral | `#ff6b5a` | Icon tick horizon, "snap" on dark backgrounds |
| Sun | `#ffd9a0` | Icon sun |
| Ink | `#1c1a17` | "pick", one-colour logo |
| White | `#ffffff` | "pick" on dark backgrounds |

## Which file to use

| Need | File |
| --- | --- |
| Website header, documents (light background) | `svg/picksnap-logo.svg` or `png/picksnap-logo-1200.png` |
| Dark background | `svg/picksnap-logo-on-dark.svg` / `png/picksnap-logo-on-dark-1200.png` |
| One colour (print, stamps, watermark) | `picksnap-logo-black` / `picksnap-logo-white` |
| Icon alone | `svg/picksnap-icon.svg`, `png/picksnap-icon-<size>.png` (16 to 1024) |
| Name alone | `svg/picksnap-wordmark.svg` / `-on-dark.svg` |
| Browser tab | `web/favicon.ico`, `web/favicon.svg` |
| iPhone home screen | `web/apple-touch-icon.png` (180) |
| Android / installable web app | `web/icon-192.png`, `web/icon-512.png`, `web/icon-maskable-512.png` |
| WhatsApp / Instagram / Facebook profile | `social/whatsapp-profile-640.png` (square, the app crops it to a circle) |
| Link preview when a link is shared | `social/og-image-1200x630.png` |
| Cover / banner | `social/cover-1500x500.png` |
| App stores | `social/app-icon-1024.png` |

## Rules

- Keep clear space around the logo of at least a quarter of the icon's height on every side.
- Smallest size: the full logo 100 px wide on screen (25 mm in print); below that use the icon alone.
- Don't stretch, recolour, add shadows, or put the colour logo on a busy photo; use the
  one-colour white logo over photos.

## Font

Sora (SIL Open Font License, free for any use, `font/OFL.txt`). Use Sora SemiBold for
headings that should match the logo. `source/` holds the scripts that made these files.
